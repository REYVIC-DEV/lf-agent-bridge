Phase 1 detail — speed

Fast in the lab, fast in the field

Measured through Google's PageSpeed Insights API — the runbook's ground truth — at both form factors, plus whatever real-user Core Web Vitals Google holds for these URLs.

Speed is not a problem on any of these pages. Ten of eleven score 97–100 on mobile, all eleven score 92–100 on desktop, total blocking time is 0 ms on ten of eleven, and CLS is 0.000 across the board — the font-preload recipe this platform needs is doing its job. Agentic Browsing passes on all eleven. Nothing in the fix list further down is a speed fix.

One caveat worth recording. PSI's crawl loads 130 KiB of each page, while a real Chromium session loads 1,100 KiB — the GTM / PostHog / Aimerce stack (~740 KB, of which Lighthouse calls ~327 KB unused on load) never executes under PSI. The lab scores are genuine PSI output, but they are not measuring the page a visitor actually receives. Field data is the tie-breaker, and it favours the pages.

Issue detail — console

Zero errors, one real failed request

  • Zero console errors on all eleven pages across a full end-to-end scroll. Warnings are 4–5 per page and all of one kind: unused-preload notices for index.js and the Google Fonts stylesheet.
  • One genuine failure, on every page: fonts.googleapis.com/css?family=Inter,+InterFallback,+sans-serif returns ERR_BLOCKED_BY_ORB. The platform builds the Google Fonts URL out of the whole CSS font stack, so it asks Google for two families that don't exist. It is also pushed as an Early Hints preload, so the miss is paid for twice. Harmless to rendering — the real Inter is self-hosted — but it is a permanent failed request in every session.
  • The tracking stack fires normally. Google, DoubleClick, PostHog and Aimerce beacons show as aborted in Playwright but return 204 in Lighthouse's network log. No revenue-affecting pixel failure was found.
  • No broken images anywhere. Every real asset returns 200, served through Cloudflare's resizer.
  • Every image carries alt="" on all eleven pages. On BH, the section-5 photo is wrapped in a link, so that link has no accessible name at all.

Limitations

What this run did not test

  • Field data is origin-level, not per-URL. None of the eleven has enough traffic for URL-level CrUX, so PSI fell back to www.techunboxed.co as a whole. The FAST readings describe the origin's aggregate, not necessarily these pages.
  • PSI's lab run does not execute the analytics stack. It loads 130 KiB; a real Chromium session loads 1,100 KiB including ~740 KB of GTM, PostHog and Aimerce. The 97–100 scores are real PSI output but they are not measuring the same page a visitor gets. Field CWV is the tie-breaker and it passes.
  • UK and German pricing unverified. The store force-redirects every market path — /uk/ and /gb/ both land on /ph/ from this IP — so the PDP was only ever observed in pesos (₱2,450, 50% off ₱4,900). Whether UK RRP is £158, which "£79" and "50% off" jointly require, needs one look from a UK IP. The same applies to the German page's 92 € / 185 €.
  • Trustpilot not opened. trustpilot.com/review/hlthtrack.com returned a TLS name mismatch to curl and timed out in headless Chromium; the regional mirror also timed out. Per the runbook this is not a link failure. The 4.5-vs-4.6 conflict is established from the pages themselves; which figure is correct still needs a normal browser. The competitor Trustpilot pages were not opened either, so their quoted scores are unverified.
  • Amazon and blog destinations checked by status and title only. The four Amazon product pages returned 200 with tags intact but were not opened to confirm the listed device or price. The Further Reading mismatches were established from <title> tags, not full article reads.
  • One PSI call failed and was retried. Top5 EN desktop returned HTTP 500 on the first attempt; the retried run scored 100 and is the figure reported.
  • Not tested: checkout and post-click funnel steps, form submission, consent-banner behaviour, real devices (all viewport work is emulated Chromium), iOS Safari, screen-reader traversal, and oura-vs-hlth, excluded from scope at your request.
