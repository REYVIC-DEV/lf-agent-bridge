New this run

The blocker is gone

All 44 dead legal links now open real policy modals. The same system already running on /smartwatch-review/0sAhHP7ki — four overlays carrying Terms of Use, Privacy Policy, Editorial Standards and Affiliate Disclosure, plus its CSS and click handler — was lifted and wired into all eleven pages. Verified on every page: four overlays present, all four open, each closes on the ×, on a backdrop click and on Escape, body scroll locks while open, zero console errors.

Built slightly tighter than the source. On the reference page the triggers are still href="#" with JavaScript doing the work, so they stay dead if a script fails. Here each href points at the real overlay id (#tu-terms, #tu-priv, #tu-edit, #tu-aff) while keeping the ids the handler listens for, so the link resolves either way and the runbook's href="#" criterion is cleared outright rather than merely worked around.

Cost is 10 KB per page and nothing moved on speed — 97–99 mobile, CLS 0.000, TBT 0 ms.

Two things to check before relying on this. The policy copy is dated 23 June 2026, so someone should confirm it is still current and that it covers these eleven pages, not just the page it was written for. And the German page renders its four footer links in English, which now matters more than it did when they went nowhere.

Limitations

What this run did not test

  • PSI readings are noisy and were treated as such. Publishing purges the storefront cache, so the first measurement after a deploy reads a cold page — pages read 74 immediately after deploy and 97 once warm, repeatedly. PSI also replays a cached analysis on rapid repeat calls, which can make one bad sample look like three confirmations. Every score here was taken warm and cross-checked; where a page disagreed with itself it was re-sampled until stable.
  • Field data is origin-level, not per-URL. None of the eleven has enough traffic for URL-level CrUX, so the FAST readings describe www.techunboxed.co as a whole.
  • PSI's lab run does not execute the analytics stack. It loads 130 KiB where a real browser loads over 1 MB, because GTM, PostHog and Aimerce never fire under PSI. Field CWV is the tie-breaker and it passes.
  • Five Trustpilot URLs could not be opened. The HLTH review page and the four competitor pages all time out or fail TLS from this network. Per the runbook this is not a link failure, and they are the only non-200s among the 34 outbound targets. It does mean the 4.6 figure and the competitor scores (Whoop 3.2, Apple 1.8, Fitbit 1.6, Garmin 1.5) remain unverified against the live source; 4.6 was taken from the merchant's own PDP, which is not independent.
  • UK and German pricing unverified. The store force-redirects every market path to /ph/ from this IP, so the PDP was only ever observed in pesos. Whether UK RRP is £158 — which "£79" and "50% off" jointly require — still needs one look from a UK IP.
  • Amazon destinations checked by status and page title only. The four .de ASINs were confirmed to be live product pages for the right devices, but prices and availability were not compared against what the page claims.
  • The policy copy was not legally reviewed. It was copied verbatim from the /smartwatch-review page, is dated 23 June 2026, and was written for that page rather than these eleven. It reads as appropriate and covers sponsored content and affiliate links, but whether it is current and sufficient for these pages is a question for whoever owns compliance.
  • Not tested: checkout and post-click funnel steps, form submission, consent-banner behaviour, real devices (all viewport work is emulated Chromium), iOS Safari, and screen-reader traversal — the alt text is present and correct in the SSR HTML but was not listened to.
  • One platform curiosity, not chased: the embedded video is served as content-type: image/mp4 rather than video/mp4. It plays and supports range requests, so it is noted rather than filed.
